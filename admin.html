Administration

Supabase n'est pas configuré. Étapes : créez le projet sur supabase.com, exécutez supabase/schema.sql puis supabase/seed.sql dans SQL Editor, créez un utilisateur dans Authentication, puis renseignez l'URL et la clé dans assets/js/sb-config.js?v=23.

Connectez-vous avec votre compte admin Supabase.
